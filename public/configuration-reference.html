Configuration reference ​

Every setting outside the content types: the first-level keys of config/drupal-backend.php and the shared drupal.* settings in config/drupal.php. Content type options are in the Descriptor reference.

Before you start ​

Install the package and publish its config. The package warns about keys it does not know, so a typo such as per_pge shows up in php artisan drupal:validate and in the descriptor smoke test, with a suggestion.

Tables use these columns: the key in dot notation relative to its table, its type, the default the package applies when the key is missing, and the effect. ?string means a string or null.

The two config files ​

FileHoldsMerge with package defaults
config/drupal-backend.phpThe descriptorFirst level only. A key you set replaces the package's whole section.
config/drupal.phpHTTP and cache settings shared by all SourcesKey by key. A partial file keeps the other defaults.

Top level ​

php
'sources' => [
    'default' => [
        'base_url' => 'https://drupal.test',
        'jsonapi_path' => '/jsonapi',
        'files_path' => '/sites/default/files',
        'webhook' => ['secret' => 'shared-secret', 'tolerance' => 30],
    ],
    'reviews' => [
        'base_url' => 'https://reviews.test',
        'jsonapi_path' => '/api',
        'frontend_url' => 'https://reviews.example',
    ],
],
KeyTypeDefaultEffect
schema_versionint2Must equal the version the package reads. Any other value stops the app at boot, also in production.
sourcesmap[]One Drupal backend per entry. See Sources.
default_source?stringThe Source named default, else the first oneSource used by content types without source and by code that asks for no particular Source.
content_typesmap[]The content types. With none, the package registers no routes and does nothing. See the Descriptor reference.
searchmap[]Search. See Search.
routesmap[]Content routes. See Routes.
webhookmap[]Webhook defaults. See Webhook.
limitsmap[]Rate limits. See Rate limits.

Sources ​

Each key of sources names a Source. The keys below are set per Source.

KeyTypeDefaultEffect
base_urlstringrequiredOrigin of Drupal. A trailing slash is removed. It also prefixes image URIs and the Decoupled Router address.
jsonapi_pathstring/jsonapiPath of the JSON:API root. Resolved paths must start with it.
files_pathstring''Path of Drupal's public files. When set, src and href values in HTML fields that start with it are rewritten to absolute URLs on base_url.
frontend_url?stringnullAddress of the frontend as Drupal knows it. Links to Drupal in HTML fields are rewritten to it, or to APP_URL when null. The contract shows it as the webhook host.
webhook.secret?stringnullShared secret for the webhook. Empty means the Source's webhook answers 404.
webhook.tolerance?intThe global webhook.toleranceSeconds of clock difference accepted for this Source.
flush.also.sourceslist of strings[]Sources flushed together with this one. Follows chains and survives cycles. Unknown names fail validation.
timeoutintdrupal.timeoutRequest timeout for this Source, in seconds.
connect_timeoutintdrupal.connect_timeoutConnection timeout for this Source, in seconds.
retriesintdrupal.retriesExtra attempts for this Source.
retry_delay_msintdrupal.retry_delay_msPause between attempts for this Source, in milliseconds.

The four HTTP keys override the shared drupal.* values for one Source. Cache windows cannot be overridden per Source. Source names used in the webhook URL may contain letters, digits, _ and -.

Search ​

The search section turns on the search page and suggestions. Validation of this section runs only when enabled is true. Settings of an installed search extension live in its own file; see the Index extension.

php
'search' => [
    'enabled' => true,
    'tabs' => ['talk', 'workshop', 'topic', 'track'],
    'suggestions' => ['limit' => 10, 'quotas' => ['talk' => 5, 'workshop' => 2, 'topic' => 1, 'track' => 2]],
],
KeyTypeDefaultEffect
enabledboolfalseRegisters the search page and suggestions routes and turns on search validation.
tabslist of stringssearchable types in descriptor orderContent type keys shown as tabs, in order. Each must be searchable and listed once. The first is the default tab.
per_pageint18Results per page.
native_limitint50page[limit] of every native search and related request. JSON:API allows at most 50 on a default Drupal site. Configured, never discovered; drupal:validate prints it.
cacheint60Seconds a search result is served without refetching. 0 disables search caching.
suggestions.limitint10Most suggestions in total and per type.
suggestions.quotasmap[]Maximum suggestions per content type key. Unused places go to the next tab. Unknown keys fail validation.
term.minint2Fewest letters or digits in a usable term. Also the shortest suggestion query. The error message follows it.
term.maxint100Characters kept from the typed term.
term.max_wordsint10Words kept from the typed term.

KeyTypeDefaultEffect
autobooltrueThe package registers the content routes. Set false and call Route::drupalContent() yourself to place them.

Rate limits ​

Requests per minute and client IP. Redefine a limiter with RateLimiter::for() for more control.

KeyTypeDefaultEffect
contentint120Limiter content: item, listing and page routes and the search page.
search_suggestint60Limiter search-suggest: the suggestions endpoint.
drupal_webhookint60Limiter drupal-webhook: the webhook routes.

Documentation route ​

The documentation is served by the separate proteo/drupal-backend-docs package, which reads config/drupal-backend-docs.php. It is not a key of config/drupal-backend.php.

KeyTypeDefaultEffect
enabled?boolnullnull serves /backend-docs everywhere except production. true always serves it. false always answers 404.

Shared settings ​

These settings live in config/drupal.php and apply to every Source. The package ships the defaults; each reads an environment variable.

KeyTypeDefaultEffect
drupal.connect_timeoutint3Seconds to wait for a connection. Variable DRUPAL_CONNECT_TIMEOUT.
drupal.timeoutint10Seconds to wait for a whole request. Variable DRUPAL_TIMEOUT.
drupal.retriesint2Extra attempts for a GET request after a connection error or a 5xx answer. Variable DRUPAL_RETRIES.
drupal.retry_delay_msint200Pause between attempts, in milliseconds. Variable DRUPAL_RETRY_DELAY_MS.
drupal.cache.enabledbooltruefalse bypasses every cache layer. Variable DRUPAL_CACHE_ENABLED.
drupal.cache.freshint300Seconds an entry is served without revalidation. Variable DRUPAL_CACHE_FRESH.
drupal.cache.staleint86400Seconds past the fresh window that a stale copy is served. Variable DRUPAL_CACHE_STALE.
drupal.cache.negativeint60Seconds an unknown alias is remembered. Variable DRUPAL_CACHE_NEGATIVE.
drupal.cache.store?stringnullCache store for package entries. null uses the default store. Variable DRUPAL_CACHE_STORE.
drupal.related.max_requestsint12Most requests one related content call may send (target types times criteria). More throws InvalidRelatedRequest. Variable DRUPAL_RELATED_MAX_REQUESTS.

The package reads no other environment variables. Names such as DRUPAL_BASE_URL and WEBHOOK_SECRET are conventions of your own config/drupal-backend.php; see Installation.
